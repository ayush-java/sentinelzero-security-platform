# 🛡️ SentinelZero

## 🚀 Overview

SentinelZero is a cloud-hosted cybersecurity platform designed to simulate enterprise security operations and cloud security monitoring workflows.

Built with React, Flask, AWS, Nginx, Gunicorn, and Cloudflare, the platform demonstrates real-world cloud deployment, secure authentication, threat monitoring, IAM security analytics, and incident response visualization.

### Key Features

* Real-time threat monitoring
* Secure authentication system
* Google reCAPTCHA protection
* IAM security analytics
* Incident management dashboards
* Cloud infrastructure monitoring
* MITRE ATT&CK visualization
* AWS cloud deployment
* HTTPS SSL encryption
* Cloudflare protection
